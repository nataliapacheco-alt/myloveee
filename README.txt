UNA CARTITA PARA TI ♡

Para abrir la página:
1. Descomprime el ZIP.
2. Abre la carpeta carta_amor.
3. Haz doble clic en index.html (se abrirá en tu navegador).

La carta se abre al pulsar el botón. Debajo aparece el reproductor de YouTube.
Se requiere conexión a internet para cargar las fuentes y el video de YouTube.

Archivos:
- index.html: estructura de la página
- styles.css: estilos, diseño y animaciones
- script.js: interacción de abrir/cerrar carta y corazones flotantes
